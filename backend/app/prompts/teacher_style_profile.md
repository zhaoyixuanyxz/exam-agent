# 朱老师命题与解析风格摘要

> 提炼自 `docs/training_parsed/` 三份训练文档，供 `teacher_style.py` 维护参考。

## 解析结构（answer_outline 固定三段）

```
【思路】点明考查核心、解题入口与关键转化。
【解答】分步推导；单选/多选须逐选项分析 A/B/C/D 判定对错及理由；填空/简答写完整计算链。
【相关知识点】条目化归纳，含易错提醒与教材衔接。
```

每题 answer_outline 建议 **800–1500 汉字**；公式用 LaTeX `$...$`。

## 学科 × 难度量表

### 数学

| 难度 | 出题标准 | 解析要点 |
|------|----------|----------|
| easy | 1–3 个基础知识点；1–2 次思维转换；无隐藏条件；计算不复杂 | 直接套用公式/定理；强调「辅助线常见套路」「被平分的弦非直径」等易错点 |
| medium | 3–4 知识点结合；计算量略增；可有隐藏条件 | 分类讨论、作图辅助线、实际应用建模（利润/取值范围） |
| hard | 3+ 大板块；细碎知识点；隐藏条件；计算量大；可跨学科 | 系数关系拓展、抛物线+一次函数综合、多情况讨论 |

### 物理

| 难度 | 出题标准 | 解析要点 |
|------|----------|----------|
| easy | 知识点直接套用；读懂题即可 | 成像规律、反射定律、杠杆平衡公式链 |
| medium | 需拆解条件意图；2–3 知识点综合 | 情境建模（斜拉桥→杠杆）、电热/多挡位电路 P=U²/R |
| hard | 特定情境难分析；理解细致；或计算量大 | 浮沉+液体密度随温度变化、多过程综合 |

### 化学

| 难度 | 出题标准 | 解析要点 |
|------|----------|----------|
| easy | 基础运用；记公式算对数 | 化学式意义 vs 原子个数比 vs 质量比；溶质质量分数与溶液均一性 |
| medium | 条件拆解；多知识点（仍较基础） | 催化剂/微观示意图、化学方程式计算、表格数据提取 |
| hard | 多步计算；环境/工业综合 | 原子守恒原料配比、污染物与微观粒子分析 |

### 通用回退（未知科目）

- easy：单一概念直接套用
- medium：2–3 知识点适度综合
- hard：综合辨析与建模，可判分、不超纲

## Few-shot 压缩示例

### 化学 · easy

```
【思路】考察化学式的意义与计算，核心是区分「原子个数比」和「元素质量比」。
【解答】A. 蔗糖含碳，属有机物，A 错。B. 12:22:11 是原子个数比非质量比，B 错。C. 纯净物分子中不含水分子，C 错。D. 氧元素质量分数公式正确，D 对。
【相关知识点】1. 有机物定义 2. 化学式宏观/微观意义 3. 元素质量比与质量分数计算；易错：勿把原子个数比当质量比。
```

### 数学 · medium

```
【思路】考查圆内接四边形与圆周角、圆心角；需考虑 A 点两种位置。
【解答】连接 OB、OC，∠BOC=90°；A 在同侧时 ∠A=45°，在异侧时 ∠A'=135°。
【相关知识点】圆周角=同弧圆心角一半；圆内接四边形对角互补；易错：漏讨论 A 的位置。
```

### 物理 · medium

```
【思路】多挡位电热器；核心：U 不变时 P=U²/R，总电阻越小功率越大。
【解答】(1) 接 de 时 R₂∥R₃ 总电阻最小，为高温挡。(2) W=UIt=33000J。(3) I=P/U=0.1A。(4) cd 串联 P=22W。
【相关知识点】并联/串联总电阻；P=UI、P=U²/R；挡位判断口诀。
```

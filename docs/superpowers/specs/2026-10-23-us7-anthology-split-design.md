# US-7 设计：合订本先确认可改的套卷边界

对应故事：`docs/2026-10-23-合订本多卷-stories.md` 的 US-7。  
对应 PRD：`docs/2026-10-23-合订本多卷-prd.md`（FR-1～FR-3 及确认硬挡）。  
架构：`docs/2026-10-23-合订本多卷-architecture-brief.md`。  
任务单：`docs/2026-10-23-合订本多卷-任务单.md` 的 US-7 行。

本设计经 brainstorming 选定「方案 1」并经 `/grill-me`（Q1–Q12）压实。

## 做法

在现有「按页拆分」上加薄层，不新开分套向导。

1. **入口（双路径，验收主走显式）**  
   - 材料旁明确按钮/选项「这是合订本 / 需要分套」：将该材料标为待分套，请求建议页码，打开现有按页拆分区并预填。  
   - 结构化异常已含「题号 order_index 重复」时：自动标为待分套，同样打开拆分区并预填。不自动替老师点确认切开。

2. **建议页码**  
   - 独立接口扫 PDF 文字层：按年份 /「20xx…中考」等标题启发式切段，返回 `ranges` 与可选 `labels`。  
   - 扫不出：返回空列表 + 短提示「请按套填写页码」。**禁止**用总页数均分假装成套。

3. **切开**  
   - 仍走现有 `POST /api/exam-papers/{paper_id}/split-by-pages`。  
   - 请求可带可选 `labels[]`（与 `ranges` 等长）；有则写入子材料 `display_name`，无则「片段 N」。  
   - **排除非试题页** = 不把那些页写进任何 range（不新增「排除」标记字段）。未盖满总页数时黄字提示「有页未纳入任何套（将排除）」，仍允许切开。

4. **确认硬挡与逃生**  
   - 待分套或已切开父材料：前端禁用「确认结构化」，确认 API 返回 400 中文说明。  
   - 「按单套继续」：待分套 → 允许按单套确认（误点合订的逃生；US-9 再验默认不强制）。须在切开之前使用。

5. **本行止点**  
   - 切开成功即 US-7 交回条件满足。不自动选中第一套去拆题（属 US-8）。

## 状态字段

`exam_papers.anthology_split_status`（字符串，默认 `none`）：

| 值 | 含义 |
|---|---|
| `none` | 普通材料；确认逻辑与今相同 |
| `needed` | 待分套；禁止确认结构化 |
| `done` | 已切开的父合订；永久禁止确认 |
| `single_ok` | 老师已选按单套继续；允许确认 |

切开成功：父 → `done`；子材料 `anthology_split_status=none`，可各自走结构化与确认。父材料保留在列表作档案。

## API（增量）

- **建议页码**：`GET` 或 `POST …/exam-papers/{paper_id}/suggest-page-ranges`（须校验会话归属）。成功体含 `ranges: [[start,end],…]`、`labels: [str,…]`（可与 ranges 等长或空）、`message`（可空提示）。失败时前端仍打开空拆分框。  
- **切开**：现有 `split-by-pages` 增加可选 `labels`；成功后写父 `done`、子 `display_name`。  
- **确认**：现有 `structured/confirm` 在 `needed`/`done` 时拒绝。  
- **按单套继续**：`POST …/papers/{paper_id}/anthology-split/single-ok`（或等价）：仅当当前为 `needed` 时改为 `single_ok`。  
- **标 needed**：合订按钮对应的写状态接口，或与 suggest 同请求副作用；重复题号路径在拉结构化/异常时由服务端或前端调用同一写状态逻辑。

不新增 MCP。密钥只在服务端。

## 前端

- 复用 Chat 内既有按页拆分 UI（逗号区间输入）；合订/重复题号时预填 `splitRanges`，有 labels 时切开请求带上。  
- 「这是合订本」「按单套继续」入口靠近目标材料 / 拆分区。  
- `StructuredResultPanel`：`needed`/`done` 时确认按钮禁用并展示原因。  
- 列表展示子材料可读名（年份 label 优先）。

## 错误与边界

- 非 PDF / 无本地路径：与现网拆分相同报错。  
- 建议失败：空预填，可手填。  
- 页码非法：现有校验。  
- 师生可见文案不带密钥、堆栈、卷子正文。  
- 未点合订且无重复题号的单套：行为不变（护栏归 US-9）。

## 怎样算过（对照 US-7 AC）

- 上传合订本（或重复题号路径）进入分套：≥2 套可改边界（预填或手填），不必从零自备全部页码即可开始编辑（启发式成功时）；启发式失败时允许手填，不记为「假均分通过」。  
- 修改后确认切开 → 多条材料；确认前不能把整本确认结构化。  
- 排除：不填某段页 → 该段不出现在试题套材料中。  
- 单元：启发式；confirm 门禁；split labels + 父 `done`；single-ok。

## 不改什么

- 不验收该套考点说明 PDF 与 20 分钟（US-8）。  
- 不把「单套默认不强制」的完整护栏验收算进本行（US-9）；但本行必须带「按单套继续」逃生。  
- 不默认多卷分析；不新增 MCP；不改批改/家长/高中；不改超时固定句语义。  
- 不另建分套状态机面板（方案 3 已否决）。

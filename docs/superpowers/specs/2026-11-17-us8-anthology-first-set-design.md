# US-8 设计：分套后至少一套能出该套考点说明

对应故事：`docs/2026-10-23-合订本多卷-stories.md` 的 US-8。  
对应 PRD：`docs/2026-10-23-合订本多卷-prd.md`（FR-4～FR-6）。  
前置：`docs/superpowers/specs/2026-10-23-us7-anthology-split-design.md`（分套、父本确认硬挡、子材料）。  
任务单：`docs/2026-10-23-合订本多卷-任务单.md` 的 US-8 行。

本设计经 brainstorming 对齐：**方案 ① + US-7 门禁复用**；**20 分钟采用方案 A**（仅产品验收秒表，应用内无计时器、不锁功能）。

## 目标（白话）

老师上传合订本并完成分套（US-7）后，**任选其中一套子材料**，走与单卷相同的：结构化 → 确认 → 考点分析 → **彩色考点说明 PDF**。产物必须绑在该子材料的 `paper_id` 上，不能用「整本父材料」的一条说明冒充通过。产品用**外挂秒表**验收首套 ≤20 分钟；系统不负责倒计时。

## 范围

### 做

- 子材料作为**唯一目标**完成结构化确认与考点说明 PDF 入库。
- 父合订（`anthology_split_status=done`）不得确认结构化、不得作为「首套达标」的说明来源。
- 现有 Agent 工具 / `knowledge_pdf` 路径按 `target_paper_id`（子套）生成并写入 `Artifact(kind=knowledge_pdf)`。
- AC-1：**套内题号**——子套确认时若检测到同套内 `order_index` 重复，**前端/接口提示**；默认**不硬拦确认**（避免误杀正常卷）；提示文案中文、可理解。
- AC-4：图文渲染超时沿用 US-6 固定句「连接超时建议重试」；已切开子材料与已入库 PDF 不撤；本产品故事内抽测一轮合订路径即可。
- 交付《US-8 产品验收记录》模板（附录），供秒表与结论落盘。

### 不做

- 应用内 20 分钟计时、告警、拦截。
- 合订内全部套都出说明（仅要求 ≥1 套）。
- 分套 UI、启发式、按单套继续（US-7 / US-9）。
- 练习卷在本行单独立项验收（沿用 US-3 能力即可）。
- 在本行单独立项验收「删 PDF 留题」（US-5 回归抽查即可）。
- 默认进入多卷分析。
- 分套后自动选中第一套并自动开拆题（US-7 已明确不在 US-7 止点做）。

## 老师路径（验收主路径）

1. 上传合订 PDF → US-7：提议/修改边界 → 确认切开 → 材料列表出现多条子材料（可读 `display_name` / 年份 label）。
2. 在材料选择器将**目标子材料**设为当前 `target_paper_id`。
3. 结构化（Agent `structure_exam_paper`）→ 查看/必要时编辑 → **在该子套上**确认结构化。
4. 考点分析 → 生成考点说明 → 产物中心出现**彩色 PDF**，来源为该子 `paper_id`。
5. 产品验收人：从步骤 1 上传起秒表，至步骤 4 PDF 可打开且入库止；填写附录验收记录。

## 与 US-7 的接口约定

| US-7 产出 | US-8 使用方式 |
|-----------|----------------|
| 父材料 `anthology_split_status=done` | 禁止对该 `paper_id` 做结构化确认；禁止以其 `knowledge_pdf` 作为 US-8 通过 |
| 子材料 `anthology_split_status=none` | 与普通单卷相同，可确认、可出说明 |
| 子材料独立 `id`、`parsed_json`、`artifacts` | 说明 PDF、考点 JSON 均挂子 `paper_id` |
| 切开时写入的 `display_name` / labels | 仅展示与选型；不改变绑定规则 |

**前置条件**：US-7 已在目标环境落地（列、API、前端门禁）。若未落地，US-8 实现计划须先合并 US-7 或等价能力，否则无验收主路径。

## 系统行为（对照 AC）

### AC-1：套内题号自洽

- **Given** 合订已分套，老师选定一套子材料并完成结构化。
- **When** 确认结构化提交前/时，服务端或前端对该子套 `parsed_json` 扫描 `order_index`（同 section 内或全局按既有结构化规则，与 V2.0 异常提示一致为佳）。
- **Then** 同套重复题号时向老师展示明确提示；默认仍允许在老师认可后确认（软拦）。验收时人工判断：套内题号在讲解意义上自洽，而非整本跨套重复仍当正常。

### AC-2：该套考点说明 PDF 入库

- **Given** 该子套 `structured_confirm_status=confirmed`。
- **When** 老师触发考点说明生成（与 US-4 相同能力）。
- **Then**：
  - 存在 `Artifact`，`kind=knowledge_pdf`，`paper_id` = 该子套 id，磁盘文件可读；
  - 父合订在同一时刻**没有**被产品当作「首套达标」的说明（父套无 confirm、无「唯一说明」代替子套）。

### AC-3：20 分钟首套（产品 Only）

- **Given** 验收材料（建议：广州中考数学 2021–2025 合订 PDF，与 US-7 一致）。
- **When** 验收人按上文老师路径完成首套，并用秒表从**上传合订 PDF**起算（含 US-7 分套耗时）。
- **Then** 耗时 ≤ 20 分钟则 AC-3 通过；**系统无**计时字段、无 UI 展示。结论写入附录验收记录。

### AC-4：超时不丢已成功步骤

- **Given** 分套已确认和/或某子套已有部分入库结果。
- **When** 后续某步触发 US-6 类连接超时。
- **Then** 用户可见「连接超时建议重试」；已存在子材料记录与已入库 PDF 仍在；同会话可重试未完成步。

## 实现策略（推荐）

采用 **最小改动 + 轻门禁**（brainstorming 方案 ① + ② 中与 US-7 重叠部分）：

1. **后端**  
   - 确认 `run_knowledge_analysis` / 说明 PDF 写入始终使用会话绑定的子 `paper_id`（既有逻辑核验；补回归测试）。  
   - `structured/confirm`：除 US-7 父本 `done`/`needed` 门外，子套走现有确认；可选增加重复 `order_index` 提示字段（不改默认确认成功语义）。  
   - 测试：子套确认 + mock knowledge PDF → artifact 行与路径；父套 confirm 仍 400。

2. **前端**  
   - 目标材料为父合订 `done` 时：结构化面板确认禁用（US-7 已有则只验）；文案引导「请先选择切开后的某一套」。  
   - 可选短 hint：「首套验收：选一套 → 确认 → 生成考点说明 PDF」。  
   - 无计时 UI。

3. **Agent / 工具**  
   - 系统上下文 `paper_id` 必须与当前目标子材料一致；不得在父 `done` 材料上调用考点说明生成作为默认路径（若工具无硬校验，用 API 层或工具入口校验 `anthology_split_status`）。

## 错误与边界

| 场景 | 期望 |
|------|------|
| 老师未切换目标，仍在父材料上点生成说明 | 门禁或明确错误，不产生「整本说明」过 US-8 |
| 多套并行半成品 | 任意一套满足 AC-2 即可；其余套不影响本故事 |
| 子套结构化未确认就生成说明 | 与现网一致拒绝或提示先确认 |
| 上传失败 / 服务未起 | 产品验收作废，不记不通过（同 PRD Edge Case） |

## 测试

### 自动化（建议）

- 集成或 API：分套后子 `paper_id` 确认 → 触发 knowledge 流程（可 mock LLM/PDF）→ 断言 `knowledge_pdf` artifact 属子套。
- 父 `done` 材料 `structured/confirm` → 400（与 US-7 同测或回归）。
- （可选）子套 parsed 含重复 `order_index` → 响应含 warning 字段或等价。

### 手工（产品 US-8 必过）

- 合订本实测主路径 + 附录秒表记录。
- 可选：中途制造一次渲染超时，核对 AC-4 文案与文件仍在。

## 不改什么

- 不新增 MCP；不改 DeepSeek 密钥形态。  
- 不改 US-4 彩色 PDF 排版标准、US-5 删除语义、US-6 超时原文。  
- 不实现 US-9 完整护栏（单套默认路径）；US-8 仅消费 US-7 切开后的子材料。

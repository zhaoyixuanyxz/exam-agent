# US-5 设计：库里的 PDF 可以留也可以删

对应故事：`docs/2026-10-21-拆卷出卷-stories.md` 的 US-5。对应需求：`docs/2026-10-21-拆卷出卷-prd.md` 的 FR-4。

## 做法

老师在「生成文件」里每一条 PDF 旁边删除。练习卷、参考答案、考点说明都可以各删各的。不点删除就是保留，不做「留下」按钮，也不另开一页库。

点删除先确认：只删这份文件，题目和考点还在。取消则什么都不改。确认后，这份 PDF 从磁盘去掉，这条产物记录也去掉，列表里不再出现。

题目、考点、会话消息、其他 PDF 都不动。整段「删除对话」仍按现在的方式清掉整个会话，不走这一条。

## 删完之后

列表只展示磁盘上还在的 PDF。没删的仍能打开。

删掉练习卷或参考答案后，被删的那一份不再算已入库。老师再生成时只补这一份；没删的练习卷或参考答案不重写。

删掉考点说明 PDF 后：「考点说明」这一条从列表拿掉。磁盘上的旧 Markdown 不删，也不再挂回列表。老师再跑一次考点分析，会再排出一份新的彩色 PDF，并重新出现在「考点说明」。

老师找题目和考点，仍用现在的拆题结果和考点结果，不靠被删的那份 PDF。

## 失败

文件已经不在了：仍去掉这条产物记录，列表当它已删，不展示技术说明。

删失败（磁盘或接口）：这条还留在「生成文件」；文件还能打开的话仍能打开。不改题目、考点或其他 PDF。页面不显示密钥、报错堆栈或卷子正文。

## 怎样算过

- 一份已入库的练习卷 PDF，老师不删，再打开库仍能打开。
- 老师删除这一份后，该 PDF 不能再打开，列表里也没有这一条。
- 删除后，这套卷的题目和考点仍能搜到。
- 参考答案、考点说明同样能各删各的；删考点说明后列表不出现 Markdown。

## 不改什么

不删题目或考点。不清空全部历史会话。不改练习卷份数、图文判定和彩色说明排版。不新开页面。不规定删除按钮的具体样式。

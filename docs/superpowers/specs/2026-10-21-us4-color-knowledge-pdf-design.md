# US-4 设计：考点说明是彩色 PDF

对应故事：`docs/2026-10-21-拆卷出卷-stories.md` 的 US-4。对应需求：`docs/2026-10-21-拆卷出卷-prd.md` 的 FR-5、AB-3。

## 做法

考点分析一成功，用已经得到的考点结果直接排出一份 PDF，马上写入现在的库。不把 Markdown 改个后缀，也不再问一次模型去写排版稿。

老师打开「生成文件」里的「考点说明」，点开就是这份 PDF。不新开页面，也不另做一个库。

磁盘上的旧 Markdown 不删。老师阅读入口不再指向它。库里已经有这份说明 PDF 时，再试就跳过，不重新生成。

## 版面

一份 PDF：

- 页头是标题（年级、科目、主题）。
- 下面每个考点一块：考点名、摘要、对应题号。
- 块与块用颜色分开（色条或浅底）。不规定具体色值。
- 不是一整块无标题、无分块、无颜色的纯文字。

## 中断

写出这份 PDF 时连接中断：

- 没写完的不入库，也不留空白页。
- 库里已经有这份说明 PDF，就留下。
- 页面只显示「连接超时建议重试」。不显示密钥、报错堆栈或卷子正文。
- 老师再试时，库里已有这份说明 PDF 就不再生成。

## 怎样算过

- 老师打开「考点说明」，文件是 PDF。
- 能看见标题、按考点分块和颜色。
- 版面不是一整块无标题、无分块、无颜色的纯文字。
- 分析成功后这份 PDF 已经在库里。

## 不改什么

不改练习卷份数和图文判定。不删库里的文件，也不删题目和考点。不清掉磁盘上的旧 Markdown。不新开页面，不另做库，不新增外部工具。不规定具体色值。

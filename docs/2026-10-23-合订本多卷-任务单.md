# 任务单：合订 PDF 先分套再按套出说明

不拆新需求，不指定源文件。每一行只派一个岗位。用户故事行做完后，由产品经理对照该条 Given/When/Then 验收。

依据：`docs/2026-10-23-合订本多卷-prd.md`、`docs/2026-10-23-合订本多卷-architecture-brief.md`。

```
US-7 分套 ──→ US-8 首套考点说明（含 20 分钟）
US-9 单套护栏（可与 US-7 并行；不挡 US-8）
```

## US-7 合订本先确认可改的套卷边界

1. **目标**：合订 PDF 在确认结构化前进入分套；系统给出可改边界，老师确认后切开为多条材料；确认前不能整本确认。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：用广州 2021–2025 合订 PDF 走通分套：可改列表、确认切开、未确认前无法整本确认、可排除非试题区间。
4. **被谁挡住**：无
5. **怎样算做完**：对照 US-7 的 Given/When/Then，由产品经理验收。
6. **不做什么**：不验收该套考点说明 PDF 与 20 分钟计时（US-8）；不改批改/家长/高中；不新增 MCP。

## US-8 分套后至少一套能出该套考点说明

1. **目标**：分套后选一套完成结构化与该套彩色考点说明 PDF；从上传合订本起 ≤20 分钟首套达标；超时不丢已成功步骤。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：一次计时记录：≥1 套「已确认结构化 + 该套考点说明 PDF」；绑定该套而非整本；超时文案与保留行为符合故事。
4. **被谁挡住**：US-7
5. **怎样算做完**：对照 US-8 的 Given/When/Then，由产品经理验收。20 分钟只在这一行判定。
6. **不做什么**：不要求合订本全部年份都出说明；不默认多卷分析；不重做 US-7 的分套 UI。

## US-9 单套卷不被强制分套

1. **目标**：单套 PDF 仍可直接结构化；误判建议分套时可按单套继续。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：一份单套中考 PDF 不强制多套确认即可结构化；以及一次「按单套继续」的结果。
4. **被谁挡住**：无（可与 US-7 并行）
5. **怎样算做完**：对照 US-9 的 Given/When/Then，由产品经理验收。
6. **不做什么**：不验收合订分套正确性；不评考点说明质量。

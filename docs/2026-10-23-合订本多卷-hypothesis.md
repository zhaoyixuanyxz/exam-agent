# Hypothesis: 合订本先认「几套卷」再拆题，老师就不会确认成超级卷

## Hypothesis Statement

**We believe that** 在老师确认结构化之前，让合订 PDF 先进入「按套卷切开并核对」的一步（系统给出可改的套卷边界，老师确认后再分别结构化）

**for** 用「一份文件含 ≥2 套逻辑卷」备课的中考老师（与拆卷出卷同一验收身份）

**will** 使老师以「按套」完成至少一套卷的结构化确认，并继续该套的考点说明与练习，而不是把整本合订确认成一张超级卷

**as measured by** 用既有广州中考数学 2021–2025 合订 PDF 做一次计时验收：能否在 **20 分钟内** 得到 **≥1 套**「题号套内自洽、已确认结构化、且已生成该套考点说明 PDF」的结果（主指标见下表）

## Background & Rationale

### Problem Context

见 `docs/2026-10-23-合订本多卷-problem-statement.md`。现状：一次上传 = 一份材料整份拆题 → 题号重复告警 → 若确认则考点/练习跟整本走。

### Supporting Evidence

- 冒烟现场：该合订本结构化约 15 大题 / 125 小题，题型加总，黄字提示 `order_index` 1–25 重复。
- 产品已有「按页拆分」与「多卷分析」，说明「多份材料」模型存在；缺口在合订本入口未强制/未辅助「先分套」。
- 操作者明确要求：合订本必须能灵活进入后续结构化与考点，不能只认单卷。

### Alternative Hypotheses Considered

- **只加强文案**：警告「请先按页拆分」但不给边界 → 可能降低误确认，但老师仍须自备页码，合订本路径仍难在 20 分钟内完成。
- **全自动切开且不可改**：边界猜错时返工更大；本假设保留「老师可改边界」以降低误切风险。
- **默认整本统一考点**：与问题陈述中的「按套可用」目标相反，不作为本假设。

## Target User Segment

### Definition

单独使用试卷考点助手、以老师身份验收的操作者；材料为中考合订 PDF（≥2 套逻辑卷装在一个文件里）。

### Segment Size

当前产品单老师验收；合订本在中考备课材料中常见（本假设用 1 份真实合订本判定，不做流量占比估计）。

### Current Behavior

上传合订本 → 一次结构化 → 见重复题号告警 → 要么硬确认超级卷，要么离开主流程去手填按页拆分。

## Success Metrics

### Primary Metric

| Metric | Current Baseline | Target | Minimum Detectable Effect |
|--------|-----------------|--------|--------------------------|
| 合订本验收：≥1 套「已确认结构化 + 该套考点说明 PDF 已入库」 | 未按套完成（整份或卡在告警） | **做到**（布尔：通过/不通过） | 不适用（单次验收，非 A/B） |

### Secondary Metrics

| Metric | Current Baseline | Expected Direction |
|--------|-----------------|-------------------|
| 该次验收中是否误把整本合订确认成唯一材料并生成「整本」考点说明 | 易发生 | 降至 **0**（不允许作为通过路径） |
| 老师是否仍须完全自备页码才能开始 | 是 | **否**（系统先给出可改边界；允许微调） |
| 从上传合订本到首套考点说明入库的耗时 | 未测 / 常中断 | **≤ 20 分钟**（秒表；只计首套达标） |

### Guardrail Metrics

| Metric | Current Value | Acceptable Range |
|--------|--------------|------------------|
| 单套卷 PDF（非合订）从上传到可确认结构化 | US-1 路径可用 | 不增加无故强制「分套」步骤；单套仍可直接结构化 |
| 已有按页拆分 / 多材料会话行为 | 可用 | 不回退；合订路径可复用材料模型 |

## Validation Approach

### Method

**原型 + 单次真人验收**（不做线上 A/B、不算样本量）。用冒烟中的广州中考数学 2021–2025 合订 PDF，产品操作者以老师身份走通；秒表记录。

### Sample Size & Duration

- Sample size: 1 份指定合订本 × 1 次操作者验收（与拆卷出卷计时验收同口径）
- Duration: 实现完成后一次会话内完成
- Traffic allocation: 不适用

### Pass/Fail Criteria

- **Validated if:** 20 分钟内完成 ≥1 套：套内题号无跨套重复告警（或告警与合订无关）、结构化已确认、该套考点说明 PDF 可打开；且未生成「整本合订」作为唯一确认材料的考点说明。
- **Invalidated if:** 仍只能整本结构化并确认；或系统给出的分套无法在合理微调后得到任一套可确认结果；或单套卷被强制要求分套导致原路径不可用。
- **Inconclusive if:** 合订本本身缺页/损坏导致无法判断边界，或验收中途环境（模型超时、本机服务中断）导致无法完成且与产品逻辑无关。

## Risks & Assumptions

### Key Assumptions

- 合订本内存在可核对的套卷边界信号（年份标题、封面、题号重号等），足以生成「可改」的初始切分。
- 老师接受「先确认几套卷再拆题」多一步，只要不用自己从零填页码。
- 「先跑通一套」作为 20 分钟目标，比「一次拆完五年并各出练习」更符合当前验收口径；其余套可同一会话继续。

### Risks

- 边界提议不准 → 老师微调成本仍高 → 假设在「不必自备页码」上失败。
- 答案册/说明页被当成一套卷 → 污染材料列表。
- 与「多卷分析」预期混淆：本假设只验证「分开后的单套考点」，不验证多年对比。

84%相关知识点分析：这道题是电学与热学的综合应用题，考察了三个核心知识点：1. 物态变化：水沸腾由液态变为气态，属于汽化现象，汽化过程需要吸热；2. 纯电阻电路的电功率计算：利用公式P=U²/R直接计算功率，该公式适用于纯电阻用电器；3. 比热容与加热效率：利用Q吸=cmΔt计算水吸收的热量，再通过η=Q吸/W计算加热效率，加热效率反映了电能转化为水的内能的比例，效率越高说明电能利用率越高。例3：思路：这道题考察多挡位电热器的电路分析与计算，核心是根据开关位置判断电路连接方式，再结合电功率、电能公式计算各挡位的电流、功率和电能。解题关键是理解“电压不变时，总电阻越小，功率越大”的规律。(1) 旋转开关转至______（选填“ab”、“bc”、“cd”或“de”）时，电热敷腰带处于高温挡工作，理由是：______；答：开关转至de时，电热敷腰带处于高温挡工作。理由：家庭电路电压不变，根据电功率公式P=U²/R，电路总电阻越小，功率越大。开关接de时，R₂与R₃并联，总电阻最小，功率最大，因此为高温挡。(2) 22W / 220V = 0.1 A(4) 旋转开关转至cd时，求电热敷腰带的功率。开关接cd时，R₁与R₂串联，已知R₁=R₂=1100Ω，电路总电阻R总 = R₁ + R₂ = 1100Ω + 1100Ω = 2200Ω根据电功率公式：P=U²/R总代入数据：P = (220V)² / 2200Ω = 48400 / 2200 = 22 W 相关知识点分析：这道题是多挡位电热器的典型综合题，考察了四个核心知识点：1. 多挡位电路分析：利用P=U²/R判断挡位高低，电压不变时，并联电阻越多（总电阻越小）功率越大，串联电阻越多（总电阻越大）功率越小；2. 电能计算：利用W=UIt计算电路消耗的电能；3. 电功率与电流的关系：利用P=UI计算电路电流，或变形公式I=P/U；4. 串联电路的总电阻计算：串联电路总电阻等于各分电阻之和，再结合P=U²/R计算功率。 受力示意图：小球b悬浮，受到竖直向下的重力G和竖直向上的浮力F浮，两个力大小相等、方向相反，作用在同一直线上。在方框的“·”上，画一个向下的箭头标G，再画一个向上的箭头标F浮，两个箭头长度相等。② 求此时b受到的浮力：小球b悬浮，根据悬浮条件，浮力等于重力：F浮 = G = mg已知m=4×10⁻³kg，g=10N/kg，代入得：F浮 = 4×10⁻³kg × 10N/kg = 0.04 N③

## 3. 常见情况：改乱了但还没提交

只丢弃**工作区**修改（未 `git add` / 已 add 但未 commit 时也可用）：

```powershell
cd c:\Users\zhaoy\Desktop\试卷考点解析式agent\exam-agent
git restore .
```

若只想恢复**某一个文件**：

```powershell
git restore path\to\file
```

---

## 4. 常见情况：已经提交，想整库回到基线标签

**会丢掉该标签之后的所有本地提交**（未推送的也会没）。确认没有需要保留的提交后再执行。

```powershell
cd c:\Users\zhaoy\Desktop\试卷考点解析式agent\exam-agent
git fetch --tags
git reset --hard baseline-2026-04-24-1
```

回到**某次提交的哈希**（先 `git log --oneline` 查哈希）：

```powershell
git reset --hard <提交的短哈希或完整哈希>
```

---

## 5. 想对比旧版，但暂时不删当前分支

**临时切到标签上看代码**（处于「分离 HEAD」，不适合长期开发）：

```powershell
cd c:\Users\zhaoy\Desktop\试卷考点解析式agent\exam-agent
git checkout baseline-2026-04-24-1
```

看完后回到日常开发分支（默认多为 `master`）：

```powershell
git checkout master
```

**从基线拉一条新分支做实验**（不破坏 `master`）：

```powershell
git checkout -b try-from-baseline baseline-2026-04-24-1
```

## 6. 满意某一版时，自己再打一个新基线标签

便于以后回退到「今天这一版」：

```powershell
cd c:\Users\zhaoy\Desktop\试卷考点解析式agent\exam-agent
git add -A
git status
git commit -m "snapshot: 描述本次稳定点"
git tag -a baseline-YYYY-MM-DD -m "说明：可回退基线"
```

将 `baseline-YYYY-MM-DD` 换成实际日期或你喜欢的名字。

---

## 7. 已经 `git push` 到远程之后

- **多人协作**：优先用 `git revert` 按提交逐条撤销，避免改写远程历史。
- **仅自己用、且确定要远程也回到旧版**：需要 `git push --force`（有风险，需团队约定）。

远程场景较复杂，出事时先把当前分支名、`git log -5 --oneline` 保存下来再操作。

---

## 8. 本仓库里通常不会进版本库的内容

`.gitignore` 会忽略例如：`node_modules/`、`data/`、`.env`、`*.db`、虚拟环境等。回退代码版本**不会**恢复这些本地数据或密钥；若误删，需从备份或重新配置环境变量恢复。

## 9. 速查命令表

| 目的 | 命令 |
|------|------|
| 看状态 | `git status` |
| 看最近提交 | `git log --oneline -10` |
| 丢弃未提交改动 | `git restore .` |

| 临时看标签 | `git checkout baseline-2026-04-24-1` 再 `git checkout master` |
| 列标签 | `git tag -l` |

# 任务单：试卷拆完即出卷

不拆新需求，不指定源文件。每一行只派一个岗位。用户故事行做完后，由产品经理对照该条 Given/When/Then 验收。

```
US-1 进卷 ─────────────┐
                       │
US-2 考点 ─┬→ US-3 练习卷 ─┼→ US-6 计时与超时
           └→ US-4 彩色说明 ─┘
                 US-3 → US-5 保留或删除
```

## US-1 任何形式的卷都能进拆题

1. **目标**：电子版、Word、拍照、扫描件都能进入现有拆题流程。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：老师可以用这四种来源各交一份卷，并看到它们进入拆题。
4. **被谁挡住**：无
5. **怎样算做完**：对照 US-1 的 Given/When/Then，由产品经理验收。
6. **不做什么**：不验收考点对不对，不出练习卷，不加家长或高中。

## US-2 每一题都有考点

1. **目标**：拆完的每一题至少有一个考点，一题可以有多个。认不出的页不编题。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：一套已拆完的卷，老师能逐题看见考点。无法辨认的一页不产生新题。
4. **被谁挡住**：无。现有电子版已能进拆题，本行不等人补扫描件。
5. **怎样算做完**：对照 US-2 的 Given/When/Then，由产品经理验收。
6. **不做什么**：不对照教纲做覆盖表，不批改，不打分。

## US-3 每个考点一份带图文的练习卷

1. **目标**：这套卷上每个考点一份练习卷 PDF，打开能看见图文，生成后就在库里。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：考点个数与入库练习卷份数一致的一套结果。
4. **被谁挡住**：US-2
5. **怎样算做完**：对照 US-3 的 Given/When/Then，由产品经理验收。
6. **不做什么**：不把彩色考点说明算进这一行，不为了赶时间少出几份。

## US-4 考点说明是彩色 PDF

1. **目标**：老师打开的考点说明是有标题、分块和颜色的 PDF。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：一份老师能打开的彩色排版考点说明 PDF。
4. **被谁挡住**：US-2
5. **怎样算做完**：对照 US-4 的 Given/When/Then，由产品经理验收。
6. **不做什么**：不负责练习卷图文，不清掉磁盘上的旧 Markdown 文件。

## US-5 库里的 PDF 可以留也可以删

1. **目标**：老师可以留下一份已入库的练习卷 PDF，也可以只删掉这一份文件。题目和考点还在。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：一次保留和一次删除的结果。删除后文件打不开，题目和考点仍能搜到。
4. **被谁挡住**：US-3
5. **怎样算做完**：对照 US-5 的 Given/When/Then，由产品经理验收。
6. **不做什么**：不删除题目或考点，不清空全部历史会话。

## US-6 超时有提示，已入库的卷还在

1. **目标**：从提交卷子到练习卷和彩色说明都入库可以计时。图文渲染连接超时时，当页显示「连接超时建议重试」，已入库 PDF 不撤，同一会话可以接着做未完成的一步。
2. **岗位**：软件实现（`brainstorming`）
3. **交回**：一次完整计时记录（含页数和形式），以及一次超时当页的文案和库内文件仍在的结果。
4. **被谁挡住**：US-3、US-4
5. **怎样算做完**：对照 US-6 的 Given/When/Then，由产品经理验收。不超过 20 分钟只在这一行判定。
6. **不做什么**：不设可用性百分比，不在超时页展示密钥、堆栈或卷子正文，不为了卡时间砍掉彩色 PDF 或「一个考点一份卷」。

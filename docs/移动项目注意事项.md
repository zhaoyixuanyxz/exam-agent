# 移动项目文件夹：用户注意事项

把 **`exam-agent`** 整目录复制或剪切到另一磁盘、另一用户名目录、或重命名上级文件夹后，部分工具仍记着**旧绝对路径**，容易导致后端起不来、前端代理报 `ECONNREFUSED 127.0.0.1:8000`。按本文检查即可避免常见问题。

仓库根目录示例（请换成你本机实际路径）：

`c:\Users\zhaoy\Desktop\试卷考点解析式agent\exam-agent`

---

## 1. 必做：重建后端虚拟环境（`.venv`）

Python 在 `backend\.venv\Scripts\` 下的 **`python.exe`、`uvicorn.exe` 等启动器会写入创建时的路径**。项目移动后，这些指向旧目录，常见报错包括：

- `Fatal error in launcher: Unable to create process using '"…旧路径…\python.exe"' …`
- 后端窗口一闪而过或无法监听 `8000` 端口

**正确做法**：不要复制旧机器的 `.venv`，在新位置重新创建并安装依赖。

在 **PowerShell** 中（路径按你的实际目录修改）：

```powershell
Set-Location -LiteralPath 'c:\Users\zhaoy\Desktop\试卷考点解析式agent\exam-agent\backend'
Remove-Item -Recurse -Force .venv
python -m venv .venv
.\.venv\Scripts\pip.exe install -e ".[dev]"
```

- 若提示找不到 `python`，可改用：`py -3.12 -m venv .venv`（版本号按本机安装调整）。
- 依赖以仓库内 `backend\pyproject.toml` 为准；其中已包含 **`langgraph-checkpoint-sqlite`** 等，与 LangGraph 新版拆分包一致，勿漏装。

---

## 2. 建议：前端依赖（`node_modules`）

`frontend\node_modules` 一般**可以**随文件夹一起移动，但在换盘符、换 Node 版本或出现异常时，更稳妥是删掉重装：

```powershell
Set-Location -LiteralPath 'c:\Users\zhaoy\Desktop\试卷考点解析式agent\exam-agent\frontend'
Remove-Item -Recurse -Force node_modules -ErrorAction SilentlyContinue
npm install
```

---

## 3. 环境与密钥：`.env` 不会进 Git

`backend\.env` 通常在 `.gitignore` 中，**克隆或只拷仓库时可能没有**。请：

1. 复制旧目录下的 `backend\.env`，或  
2. 将仓库根目录的 `.env.example` 复制为 `backend\.env`，再填入 **`DEEPSEEK_API_KEY`** 等变量。

未配置 API Key 时，界面可能能开，但调用模型会失败。

---

## 4. 路径含中文或非 ASCII 字符

本项目路径可能包含中文（例如 `试卷考点解析式agent`）。请注意：

- 优先使用仓库自带的 **`start.ps1` / `start.bat`**；脚本已尽量用 **工作目录 + 相对命令**（如 `python -m uvicorn`），减少对「把整条中文路径写进子进程命令行」的依赖。
- 若仍遇到乱码或脚本解析错误，可改用 **PowerShell 7+（`pwsh`）**，或确保含中文的自定义脚本以 **UTF-8 with BOM** 保存（Windows PowerShell 5.x 对无 BOM UTF-8 不友好）。

---

## 5. Git 与数据目录

- **`.git` 历史**可随文件夹一起移动，一般无需额外操作。
- **`data/`、`*.db` 等**若被 `.gitignore` 忽略，不会出现在克隆结果里；若你需要历史对话或本地导出文件，请**单独备份**这些目录后再迁移。

---

## 6. 迁移后自检清单

| 步骤 | 说明 |
|------|------|
| 重建 `backend\.venv` | 见上文第 1 节 |
| 确认 `backend\.env` | 见第 3 节 |
| 需要时重装前端依赖 | 见第 2 节 |
| 启动 | 在 `exam-agent` 根目录运行 `start.bat` 或 `.\start.ps1` |
| 验证后端 | 浏览器打开 `http://127.0.0.1:8000/docs` |
| 验证前端 | `http://127.0.0.1:5173`，且控制台无 `proxy error … 8000` |

---

## 7. 与版本回退的关系

代码版本仍用 Git 标签回退即可，说明见 **`docs/版本回退指南.md`**。  
注意：**回退 Git 不会修复**因移动目录而损坏的 `.venv`；路径一变，仍应按本文 **第 1 节** 重建虚拟环境。

---

若移动后仍有报错，请保留 **后端 PowerShell 窗口中的完整红字报错**（或截图），便于对照「旧路径启动器」或「缺依赖」等问题排查。

# PRD: 试卷拆完即出卷，并留下能看的彩色考点说明

冲突时以本文件和同目录的 `2026-10-21-拆卷出卷-stories.md` 为准。`docs/需求文档.md` 仍保留，其中 Markdown 考点说明、一次最多 8 个考点、只强调电子版，以本文件为准。

## Overview

### Problem Statement

老师拿到一套中考卷之后，要手翻才能讲考点。现有助手能上传、拆题、把题放进题库，考点说明仍是纯文字 Markdown，看着不舒服。练习卷有默认批量上限。图文渲染如果连接超时，老师看不到一句能照着做的提示。

### Solution Summary

老师交来一套卷，形式不限。系统拆题，每一题至少一个考点，按考点出带图文的练习卷并入库，同时给出有排版的彩色考点说明 PDF。老师可以保留或删除库里的 PDF。渲染连接超时时，前端显示「连接超时建议重试」，已入库的文件不撤。

### Target Users

单独一位老师。这次由产品操作者以老师身份验收。不包含家长、学生，也不包含教研组里的其他人。

## Goals & Success Metrics

### Goals

1. 一套卷从提交到练习卷和图文都入库，不超过 20 分钟。
2. 老师打开的考点说明是彩色排版 PDF，不是纯文字稿。
3. 超时有一句固定提示，已经入库的 PDF 还在。

### Success Metrics

| Metric | Current Baseline | Target | Timeline |
|---|---|---|---|
| 提交卷子到练习卷和彩色考点说明都入库的耗时 | 未测 | 不超过 20 分钟 | 实现完成后一次计时 |
| 没有考点的题数 | 未测 | 0；一题可以有多个考点 | 同一次计时 |
| 老师阅读的考点说明 | Markdown | 有标题、考点分块和颜色的 PDF | 同一次计时 |
| 库里练习卷 PDF 可单独保留或删除 | 能生成，删除规则未按此验收 | 删文件后该 PDF 消失，题目和考点还在 | 同一次计时 |
| 渲染连接超时的页面文案 | 未按此验收 | 前端可见「连接超时建议重试」 | 同一次验收 |

### Non-Goals

- 不把 20 分钟做成线上分流实验。
- 不对照教纲做一份标准考点表。
- 不批改、不打分、不做高中、不加家长入口。

## User Stories

| ID | User Story | Priority |
|---|---|---|
| US-1 | 作为老师，我要交任何形式的卷子，以便扫描件和电子版走同一条流程 | P0 |
| US-2 | 作为老师，我要每一题至少有一个考点，以便讲解时找得到 | P0 |
| US-3 | 作为老师，我要每个考点一份带图文的练习卷并自动入库，以便讲完能留着 | P0 |
| US-4 | 作为老师，我要彩色排版的考点说明 PDF，以便不用看纯文字稿 | P0 |
| US-5 | 作为老师，我要自行保留或删除库里的 PDF，以便库不被不要的卷占满 | P0 |
| US-6 | 作为老师，我要在渲染超时的当页看到「连接超时建议重试」，以便知道可以再试 | P0 |

验收标准见 `docs/2026-10-21-拆卷出卷-stories.md`。

## Scope

### In Scope

- 电子版、Word、拍照、扫描件进入同一条拆题流程。
- 每一题至少一个考点，允许多个。
- 这套卷上拆出的每个考点各出一份练习卷，含图文，生成即入库。
- 老师阅读的考点说明改为彩色排版 PDF。
- 库内 PDF 可单独保留或删除。删除只移除该 PDF 文件。
- 图文渲染连接超时：前端显示「连接超时建议重试」。已入库 PDF 保留。老师在同一会话重试未完成的一步。
- 用老师带来的一套卷做一次计时验收，并记下页数和形式。

### Out of Scope

- 批改、打分、分数册。
- 高中卷、家长账号或家长入口。
- 用教纲清单逐条判定「考点覆盖完整」。
- 新增 MCP。
- 为这次单独立一个可用性百分比目标。

### Future Considerations

- 解除「只做初中、不给家长、不批改」是以后的产品，这次不预做开关。以后的形态另写新日期的文档，不改本文件。
- 留学和保险的时效改造不在这份 PRD 里。它们各自写在自己的仓库。

## Solution Design

### Functional Requirements

#### 进卷和拆题

- FR-1: 老师提交的卷可以是电子版 PDF、Word、拍照或扫描件。系统用同一条流程接收，不因形式拒绝进入拆题。
- FR-2: 拆出的每一题至少有一个考点，可以有多个。老师能在结果里看见每题的考点。

#### 出卷和说明

- FR-3: 这套卷上的每个考点生成一份练习卷 PDF，卷内包含题目所需的图文。每份生成完成就入库。
- FR-4: 老师对库里的每一份 PDF 可以保留，也可以删除。删除后该 PDF 文件不可再打开。对应题目和考点仍可搜索。
- FR-5: 交给老师阅读的考点说明是彩色排版 PDF，含标题、按考点分块和颜色。纯文字 Markdown 不是老师阅读的那一版。

#### 计时和超时

- FR-6: 验收计时从老师提交卷子开始，到该卷的练习卷 PDF 和彩色考点说明 PDF 都已入库结束。
- FR-7: 图文渲染过程中连接超时，前端页面直接显示「连接超时建议重试」。文案用这一句。
- FR-8: 超时不删除超时前已入库的 PDF。老师留在当前会话，重试尚未完成的生成，不从头清掉已成功的文件。

#### 边界

- FR-9: 这次不提供批改、打分、高中卷和家长入口。

### User Experience

老师提交一卷，等拆题、练习卷和彩色说明。做完的 PDF 出现在库里。老师可以留下或删掉某一份。渲染超时的当页出现「连接超时建议重试」，已经做好的 PDF 仍在库里。

### Edge Cases

| Scenario | Expected Behavior |
|---|---|
| 扫描件模糊，拆不出可靠题目 | 不编造题目和考点。页面说明这页无法识别，请换清晰的一页或重试 |
| 老师要求批改、打分、高中卷，或以外人家长身份使用 | 不做这些事，并说明这次只处理初中老师的拆题和出卷 |
| 渲染超时前已有两份练习卷入库，第三份超时 | 前两份仍在。页面显示「连接超时建议重试」。重试只补未完成的生成 |
| 老师删除一份练习卷 PDF | 该文件消失。该卷对应的题目和考点仍可搜到 |
| 上传失败或服务没起来 | 这次计时作废，不记成产品不通过 |
| 一题对应多个考点 | 保留多个考点。每个考点仍各有一份练习卷 |

## AI Behavior and Evaluation

拆题、考点和练习内容由模型生成，分步验收。超时文案和删除文件不由模型决定。

### Behavior Requirements and Their Evidence

| ID | Behavior required | How it is evaluated | Passing threshold |
|---|---|---|---|
| AB-1 | 拆出的每一题至少有一个考点，允许多个 | 用当天那套卷，逐题看结果 | 没有考点的题数为 0 |
| AB-2 | 练习卷按该卷拆出的考点生成，一份考点一份卷，并带图文 | 对照该卷考点列表数入库的练习卷 PDF | 考点数与练习卷份数一致，打开后能看见图文 |
| AB-3 | 老师阅读的说明是彩色排版 PDF | 打开交给老师的那份说明 | 能看见标题、考点分块和颜色。不是纯文字稿换后缀 |
| AB-4 | 拒绝批改、打分、高中卷和家长使用 | 各用一句明确要求试一次 | 四次都不执行该动作，并说明这次不做 |
| AB-5 | 页无法识别时不编造题目和考点 | 用一页无法辨认的图试一次 | 不产生新题。页面说明无法识别 |

### Evaluation Set

- **Where the cases live:** 验收当次的记录，不另建评测集文件。
- **Slices that must be covered:** AB-1 到 AB-3 用同一套真实卷。AB-4 用四句越界要求。AB-5 用一页无法辨认的图。超时用一次渲染超时。删 PDF 用库里一份已入库文件。
- **Floor per slice:** 真实卷 1 套，覆盖拆题、考点和出卷。越界要求每种 1 句。无法识别的图 1 页。超时 1 次。删除 1 份 PDF。这些是覆盖承诺，不是失败率。
- **Held-out cases:** 没有留出集。阈值来自已对齐的假设，不是先调模型再定线。
- **Slices scored separately:** 耗时、考点、彩色 PDF、越界拒绝、无法识别、超时文案、删除 PDF，分开记。一项失败整次不通过。
- **If someone asks for a rate:** 这组用例给不出失败率。只报告每一项过或不过。

## Technical Considerations

### Constraints

- 需要可恢复的长流程。接卷和拆题、按考点出练习卷并入库、彩色考点说明，是先后的步骤。不在这份 PRD 里点名具体框架。
- 这次不新增 MCP。拆题、配图、公式和彩色 PDF 排版留在应用进程里。
- 模型 API 是外部端口。密钥只在服务端。
- 超时提示只显示「连接超时建议重试」，不带密钥、报错堆栈或卷子正文。

### Integration Points

- 模型 API：服务端调用，用于拆题、考点和练习内容。
- 本机存储：卷子和 PDF 进出应用库与导出目录。存储怎么接由实现决定。
- 前端页面：超时文案和库里的保留、删除，都在老师正在看的这一页完成。

### Data Requirements

对话、题目、考点和已入库 PDF 跟会话存放。中断后从该会话已入库的卷和 PDF 读回。超时不回滚已入库文件。删除 PDF 只删文件，不删题目和考点。

这次不设单独的可用性目标。超时前已经入库的 PDF 保留。老师重试的是还没完成的那一步。

### Stop and Escalate

| Condition | Escalate to |
|---|---|

| 删除 PDF 必须连带删掉题目才做得到 | 操作者 |

## Dependencies & Risks

### Dependencies

| Dependency | Owner | Status | Impact if Delayed |
|---|---|---|---|
| 模型 API 可用 | 操作者 | 验收时要能调用 | 计时作废 |
| 老师带来一套真实中考卷 | 操作者 | 尚未指定哪一套 | 不能做 FR-6 |
| 现有拆题和 PDF 渲染 | exam-agent | 已在仓库中 | 本 PRD 在其上改行为 |

### Risks

| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| 长卷或脏扫描把出卷和图文拖过 20 分钟 | 高 | 高 | 仍按 20 分钟判，不放宽。页数和形式写进记录 |
| 彩色排版被做成纯文字换后缀 | 中 | 高 | FR-5 要求能看见标题、分块和颜色 |
| 超时被做成静默失败或清库 | 中 | 高 | FR-7 和 FR-8 分开验收 |
